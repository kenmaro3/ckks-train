## Findings and finite fixes

1. **P2 — second-resolution runner start can be falsely rejected against fractional gate time (line 128).** The deployed queue writes gate `at` using `time.time()`, whereas `run_job.sh` writes `start`/`end` with `date -Is`, which has whole-second precision. A gate at second N + 0.75 and a legitimate runner start later in that same second produces recorded start N. `gate_at <= dates[0]` rejects that legitimate record. This is possible for a sufficiently quick clone/setup and is not prevented by the queue contract; the queue's own terminal validator already uses `math.floor(before)` for this reason. The existing synthetic fixture puts the gate far before the job and does not exercise this boundary.

   Finite fix: compare the start lower bound with `math.floor(gate_at)`, retaining ordered start/end and current-observation upper bound. Document that recorded second precision cannot resolve subsecond order; this does not establish historical invocation proof. Add tiny fixtures for a fractional gate and start in the same recorded second (accepted), start one whole second before that floor (refused), and end before start (refused). No source acquisition helper changes or remote run are needed.

2. **P2 — JSON nesting refusal can bypass original-byte retention (lines 93–94 and 205).** `parse_object` invokes `json.loads` on acquired raw records. Excessively nested JSON can raise `RecursionError`; `collect` catches only `OSError`, `ValueError`, `TypeError` and `OverflowError`. Such a record can be well below 8 MiB. Although `take` already saved its original base64 bytes and all earlier files, the uncaught error exits before `collect` returns and before the main block prints the capture. This violates the specified refusal behavior of preserving already acquired originals. This is a static control-flow finding, not an executed reproduction.

   Finite fix: include `RecursionError` in the bounded semantic-refusal handling (or translate it to `ValueError` inside `parse_object`) so the ordinary capture with `exit_code: 2`, error path/stage and saved originals is emitted. Add one tiny over-nested state or metadata fixture confirming refusal plus retention of the offending raw file and earlier owner/gate bytes. Do not broaden this into a generic exception swallow or alter the stable-read helper.
