## Common comparison and acquisition contract

A reader selects a fixed expected role from the actual context inventory, acquires it beneath retained trusted roots/ancestor FDs, and verifies regular-file type, owner/mode, mount, size, directory-to-entry identity and exact whole-file length/hash before and after bounded reading. Artifact FileRefs only describe that selected identity. They do not instruct the reader which root/path to open. Keep root tags Input/Source/Reviewed/Policy/Authority/Observation distinct, relative canonical paths sorted/unique where required, and original error distinctions for unknown revision/report schema, missing evidence, stale identity and malformed bytes.

All five exact compiled revisions remain `d7-inputs-v1`, `d7-implementation-v1`, `d7-layout-v1`, `d7-resource-v1`, `d7-user-v1`. Common checks derive from actual execution bytes, contract/selected receipt/materialized identity, campaign/profile, approved current policy, train receipt, executable, complete source manifest and Git revision. Compare duplicate identities and original owners; equal hashes from a different context or plan owner are insufficient. A parsed synthetic record can never construct a genuine capability.

Full requires the verified target owner, full registered-case bytes, lock/reference exact file AND payload links, lock ID, binary64 threshold, attempt and explicit predecessor, plus independently materialized selected target receipt. Quick uses the registered Full seed0 row only as provenance and a distinct operational identity for seed0/exactly two actual updates/attempt. Quick has no target, lock, threshold, predecessor or Full token. Equal registrations/inputs across branches cannot promote it.

Keep external reviewed evidence reads within the existing 8MiB raw-file limit, existing typed contract/receipt C/R limits, sidecar A=2,097,152 and Quick K=1,048,000/A. No unlimited decoder is justified by streaming hashing. Canonical source files must still include every selected train/test/order/initial-state source; a file that cannot satisfy the applicable accepted acquisition budget must remain unavailable rather than be omitted or have its limit silently raised. The source brief must state actual role/size inventory and bounded read strategy, particularly for dataset arrays, independently of the small synthetic vectors. This report does not invent an exception to schema §5.
