## 2. Ratified design decisions

| Ratified decision | Reason and rejected alternative |
|---|---|
| Production recipe v1 is native `x86_64-unknown-linux-gnu`, CPU scalar, release, no bench features | Minimal compiler/filesystem surface; all scientific profiles/seeds remain represented. Mac can compile/test pure logic and run explicitly diagnostic Iris; unsupported production capture/publication fails. This is the plaintext WRITER recipe only; scientifically matched CPU/GPU consumer readiness and their later approved build recipes remain separate. Expanding writer platform/features is another reviewed recipe, not deleting matrix rows or banning CUDA consumers. |
| Require clean tracked AND nonignored untracked Git state; no dirty production exception in v1 | Ratified architecture permits a separately reviewed dirty snapshot but does not require one. Clean-only is simpler and stops current concurrent working-tree edits from being mislabeled ready. Rejecting all untracked files is preferable to an incomplete ignore heuristic. |
| Separate embedded compile capsule from frozen postbuild receipt | An executable cannot embed its own final SHA256 without a cycle. The receipt binds capsule bytes and completed executable; a later local approval pins the receipt. Reusing runtime PATH rustc or trusting HEAD alone is insufficient. |
| Strict-prefix domain plus existing full-plan digest at exact exhaustion | Keeps the frozen full/consumed equality without redefining D6a `plan_sha256`. Re-encoding D6a's private plan grammar or hashing a receipt byte span would create conflicting algorithms. |
| ext4/XFS local directory publication, descriptor-relative operations | Existing libc supplies Linux primitives; ordinary rename can overwrite. APFS, NFS, overlayfs, FUSE, tmpfs and other types are unsupported for production until separately reviewed. This is a publication restriction, not a scientific profile exclusion. |
| Explicit trusted local approval input, separate from artifact/receipt | A self-consistent self-issued receipt is not approval. Pinning exact approval bytes makes the local trust decision inspectable; no signatures/service/global journal are introduced. |

These choices are ratified for the implementation contract; implementation ownership remains separately assigned. Future execution approval separately supplies actual source/build/approval hashes; this document invents none.

## 3. New byte domains only

Do not redefine D6c1a or D6c1b encodings. For the NEW objects below: `T`=u64LE UTF8 byte length+bytes; `B`=u64LE raw byte length+bytes; `N`=u64LE; `Q`=one explicit tag byte; `H`=T(lowercase64 SHA256); `V`=N count+ordered elements; `F32/F64`=IEEE bits LE. Header for each row is `T(hekit-study-reference-encoding-v1),T(domain)`. SHA256 hashes the entire listed byte stream. No native usize, Debug, JSON ordering or delimiter concatenation. All conversions/length additions checked.

| New domain | Exact payload order after header |
|---|---|
| `hekit-study-consumed-prefix-v1` | H(trusted full D6a plan hash), N(full update count), N(n), N(sum valid_samples of updates[0..n]), N(number of trusted checkpoints with completed_updates<=n). Only for 0<=n<U. |
| `hekit-study-plain-state-v1` | Q(dtype32/64), H(materialized input), H(selected receipt), N(completed updates), N(processed samples), V(layers in canonical graph order: T(name), V(exactly four tensors: Q(role weights0/bias1/weight_velocity2/bias_velocity3), N(rows), N(cols), V(row-major scalar F32 or F64))). |
| `hekit-study-build-files-v1` | Q(role source0/config1/dependency2/toolchain3), V(records sorted by raw path bytes: B(path), Q(absent0/regular1/symlink2), then for regular H(file bytes), for symlink B(raw link target); absent has no following payload). |
| `hekit-study-build-environment-v1` | V(sorted ASCII keys: T(key), Q(absent0/present1), B(value) only when present). Values are raw bytes, not lossy UTF8. |
| `hekit-study-compile-capsule-v1` | T(recipe version), T(session algorithm), H(source manifest), H(config manifest), H(dependency manifest), H(toolchain manifest), H(build environment), H(Cargo.lock), T(source Git SHA1), T(compiler -vV), T(cargo -V), T(target), T(host), T(profile), T(opt_level), Q(debug0/1), V(T(enabled bench feature)), T(package version), H(exact prebuild metadata stdout bytes), V(package inventory sorted by raw UTF8 ID bytes: T(package ID),B(manifest path),Q(workspace0/registry1),T(source string; empty for workspace)), V(B(exact metadata argv)), V(B(exact Cargo build argv)), B(build cwd). |
| `hekit-study-build-receipt-v1` | B(complete capsule bytes), B(complete source manifest bytes), B(complete config manifest bytes), B(complete dependency manifest bytes), B(complete toolchain manifest bytes), B(complete build environment bytes), B(executable canonical path), H(executable bytes), H(postbuild source manifest), H(postbuild config manifest), H(postbuild dependency manifest), H(postbuild toolchain manifest), H(postbuild environment), H(exact postbuild metadata stdout bytes), V(emitted linkage records sorted lexicographically by tuple (package ID,name,src_path,manifest path,kind vector,executable presence/path), comparing text as raw UTF8 and paths as raw bytes: T(package ID),B(manifest path),T(target name),B(target src_path),V(T(target kind), sorted raw UTF8),Q(executable absent0/present1),B(executable path) only if present), V(B(exact helper argv)). |
| `hekit-study-local-approval-v1` | T(approval ID), T(recipe version), T(session algorithm), V(design records sorted lexicographically by raw UTF8 path bytes, NOT encoded length prefixes: T(path),H(bytes)), T(approved source Git SHA1), H(source manifest), V(approved builds sorted by H(receipt file): H(receipt file),H(capsule),H(executable)). |

`consumed_digest(n)` rejects n>U; for n==U returns the EXISTING trusted `identity().plan_sha256()` verbatim, not the prefix-domain hash. For n<U hash the prefix row. This is a tagged-by-count algorithm, not a claim that separate-domain hashes coincide. Zero is allowed for failure/accounting tests. Quick has n=2 and checks full trusted U/samples separately; even a future U=2 would use the full hash yet remain diagnostic by mode/type. No attempt to require hash inequality at n<U; semantic completeness never rests on inequality.
Prefix binds the entire full numeric plan and the exact index cut, which uniquely selects every update and checkpoint; no duplicate plan decoder is needed. It is not a transcript proving execution. Full plan identity is always checked against trusted D6a separately.
State tensors use immutable layer accessors: weights and weight velocity have output-by-input shape; bias vectors have rows1/cols=length. Include disabled-bias zeros and zero SGD velocity, all local heads, signed zeros and every scalar in logical row-major order independent of ndarray strides. All values finite; checked shapes/names exactly match materialized graph. No empty/missing tensor; four role records in stated order. F64 uses this same domain with tag64 and eight-byte scalars, stays diagnostic. A state digest cannot be independently recomputed offline without exported final arrays; verifier labels it session-origin integrity under local trust, never independently validated trained-state content.
Manifest source paths are repository-relative UTF8 satisfying existing SourceFile rules; their B encoding uses those exact UTF8 bytes. Canonicalize each declared inventory ROOT once. Config/dependency/toolchain entry keys are lexical absolute raw Unix paths beneath that canonical root, without resolving the entry’s final symlink; absent config candidates retain their lexical absolute path. Symlinks remain forbidden for source/config. For dependency/toolchain links, separately resolve each link chain to enforce containment in its declared root, rejecting cycles/outside-root targets/special files; store each encountered link at its OWN lexical path with exact raw readlink bytes. Include the final regular target under its own lexical path, or recursively include terminal-directory contents; directories themselves have no manifest row. Multiple links to one target produce distinct link rows and ONE target row per lexical path. Deduplicate repeated traversal discoveries, then reject duplicate encoded keys; hardlinks at different lexical paths remain separate records. No following a link and replacing its row key with the target path.
New binary receipt/approval files use exactly these canonical streams, strict bounded decoding, no trailing bytes, and re-encode equality; max8MiB each, max65,536 manifest records, key/text/path<=4096, compiler text<=16384, capsule<=2MiB, max256 argv elements, max64 approved builds, max32 design records; package inventory and emitted-artifact lists each<=65,536 and charge the existing enclosing caps. All package IDs/target names/source strings<=4096; no cap increase. Source records additionally<=512 to fit existing provenance. Exceeding bounds fails; no truncation. Receipt manifest/environment blobs use only the NEW tables here: decode boundedly, require canonical re-encoding and exact hash equality to capsule fields; no opaque digest-only substitute. No identity binary grammar is decoded.
